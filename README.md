# Приложение к программному обеспечению Студента КГУ
Данный репозиторий предназначен для удобного доступа к файлам программ обучения из основного приложения [Студент КГУ](https://github.com/MichelSmirnow/KSUstudentPortal). 



## Структура приложения
Здесь представлена типизированная иерархическая направленная структура хранения данных об образовательных программах и образовательных процессах.
```
📦 Репозиторий KSUdata
├─ Название института (аббревиатура, например ИВИТШ)
│  ├─ Название специальности (Например, Информационные системы и технологии 09.03.02)
│  │  ├─ Дисциплины
│  │  │  ├─ Вспомогательные дисциплины
│  │  │  │  └─ Дисциплина
│  │  │  │     └─ Основные .pdf документы, в том числе образовательная программа дисциплины
│  │  │  ├─ Коммуникативные и социальные дисциплины
│  │  │  ├─ Математические дисциплины
│  │  │  ├─ Специальные дополнительные дисциплины
│  │  │  ├─ Специальные основные дисциплины
│  │  │  └─ Элективы и факультативы
│  │  ├─ Практика
│  │  └─ Дополнительные .pdf документы
│  └─ Другая специальность
└─ Другой институт
```
**Для соавторов**: строгое соблюдение данной структуры необходимо дял корректной работы основного приложения, так как оно использует API Github Pages (fetch-запросы) строго типизированного заложенного типа.
